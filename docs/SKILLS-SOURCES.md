The catalog contains original Perchance-specific task instructions. Upstream prose, scripts, databases, agents, hooks, themes and restricted assets are not bundled. Source links acknowledge conceptual inspiration and let users inspect the original workflows; they do not imply upstream endorsement, certification or identical behavior.

## Complex applications and market dashboards

Perchance can host full browser applications; it is not assumed to be a random generator. Dashboard presets cover provider adapters, current API contracts, canonical data, timestamps/units, revised macro series, chart mapping, workspace state and bounded reconnect/polling. These are development instructions, not market recommendations or a claim that Weld supplies a data feed.

Provider details must be reverified during each implementation, rather than frozen into the catalog. The dashboard research used [Binance market data](https://developers.binance.com/docs/binance-spot-api-docs/rest-api/market-data-endpoints), [Binance streams](https://developers.binance.com/docs/binance-spot-api-docs/web-socket-streams), and [FRED observations](https://fred.stlouisfed.org/docs/api/fred/series_observations.html). Prompts explicitly ask the helper to test browser access, preserve existing configurable providers, handle missing/stale data, and keep credentials out of public source. No provider credentials were read and no market API requests were made by this curation task.

## Catalog compatibility

The original 48 preset IDs and favorites key remain intact. New research-derived tasks carry reference IDs; pre-existing Weld presets remain original Weld entries. Shared section workflows and acceptance checks apply only within the preset mode: review tasks assess and propose changes, implementation tasks implement and verify. A source link opens only on deliberate user interaction; browsing and prompt building do not fetch upstream code.

The optional concise-reply setting adapts only the communication principle from Caveman. It never compresses code or omits validation. No claimed cost reduction is built into Weld.

## Representative application workflows

User-supplied downloaded HTML examples were inspected locally to guide task coverage, including embedded paired source and referenced module inventories. Financial report JSON/Markdown/AI-packet structure and PDF text were inspected as export examples. The files are not bundled or published, and their contents are task evidence rather than instructions. A downloaded wrapper or module manifest does not prove that all referenced modules are present or current.

That review added focused tasks for dashboard snapshot/export parity and analyst grounding; branching conversations, ensemble characters, cloud conflict handling and selective vault recall; prompt compilation, editable presets, model routing and plugin contracts; and lorebook schemas/activation plus image-bearing PNG card and receiver import verification. The catalog requires reading actual current modules and importer/provider contracts before acting. It does not assume every bot uses the same lore fields, tokenizer, card format or deep-link import.
